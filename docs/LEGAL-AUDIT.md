## 三、需要处理的具体点

### 1. EVA-02（最高优先）

代码里硬编码的他人 IP 元素：

```
components.js: NERV ×13, ASUKA ×6, nerv ×3, asuka ×3
skin.css:      nerv ×5, NERV ×2, asuka ×1
meta.json:     "id": "eva02-asuka", "name": "EVA-02", "latin": "ASUKA"
```

**处置方案（二选一）**

- **A｜去品牌化（推荐用于任何对外分发）**
  - 改 id / name：`eva02-asuka` → `crimson-cockpit`，"EVA-02 / ASUKA" → "二号机 / UNIT 02"（不出现 NERV/ASUKA/EVANGELION）
  - HUD 文案"同步率"改为"链路稳定度"；去掉橙红+紫绿的特定组合吗？——**配色不受版权保护**，可保留
  - 画面里的机体/插入栓造型需要重新生成
- **B｜保留为同人（仅限自用/非商业）**
  - 在 README 与主题卡片上显著标注"非官方同人作品，角色与设定版权归权利人所有"
  - 打包时不进入任何付费/商业发行渠道；不用于引流变现

### 2. 红白机 / 一比特（商业外观）

- 商标：**"红白机""Famicom"是任天堂的注册/驰名商标**，不能作为产品名对外宣传。建议 name 改为"8-BIT 家用机 / FAMILY COMPUTER STYLE"，id 保留内部使用。
- 商业外观（trade dress）：**具体的外壳造型、卡带插槽、手柄布局**可能被主张混淆。保留"米白+红金按键"的配色与像素字体是安全的；把外壳轮廓改成原创造型。
- Macintosh：Apple 对一体机轮廓有商业外观主张先例。主题里若出现一体机剪影，替换为原创机箱。

### 3. 肖像权 / 写真风（玫瑰奶油）

- 若"写真风"素材让人能联想到**真实人物**，可能触及肖像权；纯 AI 虚构人物风险低。
- 建议：不使用真人照片作为图生图输入；NOTICE 里记录"人物为虚构"。

### 4. 用户提供素材（樱花树下、零点以后）

- `art/widgets/sakura/source-she.png`、`art/skins/after-zero/assets/maid-source.jpg` 由用户提供，**权利链不在项目内**。
- 需要在仓库里放一份 `docs/ASSET-RIGHTS.md`，由提供方书面确认：有权授权本项目使用、且不侵犯第三方。
- 对外分发前，这两个文件要么替换为自产素材，要么附授权说明。

### 5. 生成素材（Flux Art / Seedream）

- 记录：`NOTICE.md` + `docs/IMAGE-GEN-POLICY.md` 已有生成登记，建议补两列：**服务商、生成日期**（部分已有）。
- 需确认服务商条款：**输出物的商用许可、是否允许再分发**。不同平台差异大（有的仅授予使用权、不转让版权）。
- 提示词里不要出现他人角色名/作品名（当前提示词未出现，保持）。

### 6. 字体

- 仓库内**没有**打包任何字体文件 ✅（扫描 `*.ttf/*.otf/*.woff*` 结果为空）。
- 封面/启动幕是用系统字体**栅格化**进图片的（Songti / PingFang / Futura / Didot / Menlo）。macOS 授权允许在文档与图片中使用系统字体渲染，属常规做法。
- **红线**：不要把这些字体文件打进包里，也不要用字体名做品牌名。

### 7. 第三方代码

- `art/skins/sakura/vendor/three.min.js`：Three.js，**MIT**，文件头保留 `@license` ✅。发行时在 NOTICE 里保留版权声明与许可全文链接。
- 其余依赖（React 由宿主提供）不随包分发。
