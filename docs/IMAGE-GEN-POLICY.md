# 生图 API 使用规范

> **前提：生图是按张计费的。** 当前用的是 Flux Art OpenAPI 的 `gemini-2.5-flash-image`，
> 折扣价约 **35 算力 / 张**；换更强的模型（Nano Banana Pro、Seedream 5 Pro）会到 120–250 / 张。
> 所以调用要**用在刀刃上**，能不用就不用。

## 一、优先级（从高到低）

1. **纯 CSS 能做的一律不生成**：渐变、扫描线、撕边遮罩、内阴影、光晕、网格、噪点（`repeating-linear-gradient` + `radial-gradient` 已足够）
2. **矢量能做的不生成**：图标、印章轮廓、边框花饰、按钮，用内联 SVG
3. **皮肤已有的素材优先复用**：`art/skins/<id>/assets/` 里的壁纸、头像
4. **实在需要"照片级/有机质感"才生成**：纸张纤维、锈蚀金属、木材、布料、烛光场景

## 二、明确禁止

- ❌ 用生图做**皮肤库封面** —— 用 `tools/make-cover.mjs` 拿「壁纸 + 头像 + 名称」合成（免费、可控、可复现）
- ❌ 用生图做**启动幕文字** —— 生成图只做背景，文字用 HTML 叠（模型写字会糊）
- ❌ 反复试错式重生成 —— 同一提示词最多生成 2 次，不满意就别硬凑
- ❌ 为单个皮肤生成超过 **3 张**素材

## 三、调用前的检查清单

- [ ] 这个效果 CSS 真的做不出来？
- [ ] 现有素材里没有可复用的？
- [ ] 提示词里写清了「no text / no logos / flat even lighting」？
- [ ] 比例（`aspect_ratio`）和最终用途一致？宽图别生成 1:1
- [ ] 生成后是否落到 `art/gen/` 并在 `NOTICE.md` 登记（模型 / 日期 / 用途）？

## 四点五、成本纪律（2026-11-02 追加）

- **一次只生成一张，不做备选。** 先想清楚提示词，出图即用；不满意就改提示词，不要靠多出几张来碰运气。
- 出图前先把**构图写进提示词**（人物站位、明暗分区），不要靠后期裁切反复试。
- 额度用尽时（`402 insufficient_points`）不要换模型硬试，直接停下来告诉用户。

## 五、密钥管理

- API Key **只走环境变量** `FLUX_API_KEY`，不写进仓库、不写进脚本、不进 `NOTICE.md`
- 生成脚本：`tools/gen-art.mjs`（presets：`vellum` / `famicom` / `rust` / `boot` / `edge`）
- 生成的原始 PNG 不进包体，只有压缩后的 jpg/png 会通过 `art/gen/` 被 `import-one` 内联
